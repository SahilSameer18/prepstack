# Roadmap source notes: Java & Spring Boot (11 Nov 2026)

Facts are restated in our own words. Tags: [V] read verbatim by the fetch agent, [S] from the fetch tool's summary of an unread part. Time ranges, goals, checkpoints and projects are our estimates and opinions. Written for a non-technical reader (owner rule). Status: read by us; one AI reviewer (not an outside reader).

## Pages used (all loaded, no login) and what we took
- **Dev.java "General Tutorials"**: sections: first steps; the language (basics, OOP, generics, lambdas, pattern matching, annotations, exceptions); the API (collections and streams, I/O, dates, regex, reflection, virtual threads); modules; the JVM (core tools, JFR, GC); JavaFX; certification. Used for the Java basics and concurrency (virtual threads) steps. Copyright Oracle, all rights reserved.
- **Oracle Java Tutorials** (Learning the Java Language, Collections, Exceptions, Concurrency, Generics). All carry a notice that they were written for JDK 8 and point to dev.java; the step labels say "written for JDK 8". Language lessons: OOP concepts, language basics, classes and objects, annotations, interfaces and inheritance, numbers and strings, generics, packages. Collections: introduction, interfaces, aggregate operations (streams), implementations, algorithms. Exceptions: catch or specify, try/catch/finally/try-with-resources, throwing, chained and custom exceptions, unchecked exceptions. Concurrency: processes and threads, thread objects, synchronization (interference, memory consistency, intrinsic locks), liveness (deadlock, starvation, livelock), guarded blocks, immutable objects, high-level concurrency (executors, thread pools, fork/join, concurrent collections, atomic variables).
- **HashMap, Java SE 21 API** [V]: constant-time get and put if the hash function spreads elements well; default capacity 16, load factor 0.75; not synchronized. **ArrayList API** [V for the class description]: size, isEmpty, get, set, iterator constant time; add amortized constant time; all other operations linear.
- **Maven**: the old "getting started guide" URL is a 404; the replacement `getting-started/index.html` was read (what Maven is, setup, first project from an archetype, pom.xml, directory layout, compile, test, package, dependencies; rest by summary). **JUnit User Guide** (moved to docs.junit.org; EPL 2.0): JUnit = Platform + Jupiter + Vintage; Java 17 or higher; annotations, assertions, lifecycle, parameterized tests.
- **Spring Boot project page and reference** (copyright Broadcom): stand-alone apps you "just run", embedded Tomcat/Jetty/Undertow, starters, auto-configuration, production features (metrics, health checks, externalized config). Spring Initializr (`start.spring.io`) is script-rendered and unreadable; the guides describe generating a project with it. **Spring Framework IoC page**: dependency injection and beans [S for the details]. **Spring MVC / Servlet web page**: @Controller, @RestController, @RequestMapping, @GetMapping [V]; Boot auto-configures MVC [V]; CORS and error handling exist [S].
- **Spring guides** (code Apache 2.0, text CC BY-ND 3.0): "Building a RESTful Web Service" (about 15 minutes; Java 17+; records, @RestController, @GetMapping, @RequestParam), "Accessing Data with JPA" (about 15 minutes; @Entity, @Id, @GeneratedValue, CrudRepository, findByLastName; H2), "Securing a Web Application" (about 15 minutes; form login, SecurityFilterChain, BCrypt in-memory user), "Spring Boot with Docker" (Dockerfile, non-root user, layered JAR, build image, profiles). The guide index page is script-rendered and unreadable.
- **Spring Data JPA reference**: repositories, query methods, transactions, locking, auditing. **Spring Boot SQL databases page**: spring.datasource.* settings; embedded H2/HSQL/Derby when no URL is set; HikariCP pooling preferred [V]; JPA details [S]. **Spring Security reference**: authentication, authorization, protection against common attacks (CSRF, headers), OAuth2 login and resource server. **Spring Boot testing page**: spring-boot-starter-test brings JUnit Jupiter, AssertJ and Hamcrest; Testcontainers is listed.

## Added after the accuracy review (11 Nov 2026)
